# Balayani Wellness Escape

A polished, responsive tourism website based on the supplied Balayani Wellness Escape brochure and final examination requirements.

## Sections
Home, About, Tourism Package and Three Day Itinerary, Experience Highlights, Gallery, Destination and Map, Travel Guide, Booking and Inquiry, Contact Us, and Footer.

## Features
- Professional responsive tourism layout
- Page-specific photographs across major sections
- Expanded gallery using the supplied visual assets
- Click-to-enlarge image lightbox
- Active navigation highlighting while scrolling
- Mobile navigation menu
- Back-to-top button
- Booking and inquiry form with front-end confirmation message
- Google Map embed for Puerto Galera
- Clear calls to action and package pricing
- Contact email: edrianebalayaniwellness@gmail.com
- No QR-code images are used

## Image note
Visual assets are based on photographs supplied with the Balayani Wellness Escape project. Crops of those supplied photographs are used to increase visual coverage without adding unrelated or uncredited images.

## Open the site
Open index.html in a browser, or run the folder using Laragon or VS Code Live Server.

## Booking note
The inquiry form is a front-end academic demonstration. Final availability, rates, ferry schedules, and activities should be confirmed with the Balayani Travel and Wellness Desk before payment.
